## Self-improvement: learn skills from experience

At the end of each task, after it is verified and committed, run the
`skill-learning` skill check. If the task took about 5 or more tool calls, hit
errors before it worked, got a correction from the user, or showed that a
skill you used is wrong, then patch the matching skill or create a new one.
Copy it to the skills folders of the other AIs on this computer and commit.
Most tasks need no skill: skip silently when none of these is true.
